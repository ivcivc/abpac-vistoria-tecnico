# Guia do Usuario - Vistoria Tecnico

## Introducao

O **Vistoria Tecnico** e seu aplicativo para realizar vistorias de equipamentos de forma rapida e eficiente, mesmo sem conexao com a internet.

## Primeiros Passos

### 1. Acesso ao Sistema

1. **Abra o aplicativo** no seu dispositivo movel
2. **Digite suas credenciais** de tecnico
3. **Confirme o login** - seus dados serao salvos para uso offline

### 2. Sincronizacao Inicial

Apos o primeiro login:
- O app **baixara automaticamente** suas vistorias pendentes
- **Aguarde a sincronizacao** completa antes de sair de area com internet
- Voce vera o status "Sincronizado" quando tudo estiver pronto

## Realizando uma Vistoria

### Iniciando uma Vistoria

1. **Selecione a vistoria** na lista principal
2. **Toque em "Iniciar Vistoria"**
3. **Confirme os dados** do cliente e localizacao

### Verificando Itens

Para cada item da vistoria:

#### Adicionando Evidencias
1. **Toque no item** para abrir os detalhes
2. **Use "Adicionar Foto"** para capturar evidencias
3. **Tire multiplas fotos** se necessario
4. **Adicione observacoes** especificas do item

#### Marcando Status
- **Verde**: Item em perfeito estado
- **Amarelo**: Item com pequenos problemas
- **Vermelho**: Item com problemas graves
- **Cinza**: Item nao verificado

### Adicionando Despesas

1. **Acesse "Despesas"** no menu da vistoria
2. **Toque em "Nova Despesa"**
3. **Preencha os dados:**
   - Tipo de despesa
   - Valor
   - Descricao
   - Anexe o comprovante (foto)

### Finalizando a Vistoria

1. **Revise todos os itens** verificados
2. **Confirme todas as fotos** estao anexadas
3. **Adicione observacoes gerais** se necessario
4. **Toque em "Concluir Vistoria"**
5. **Confirme a conclusao**

## Modo Offline

### Como Funciona

O aplicativo funciona **totalmente offline** apos a sincronizacao inicial:
- Visualizar vistorias
- Adicionar fotos
- Marcar status dos itens
- Adicionar despesas
- Concluir vistorias

### Sincronizacao Automatica

Quando voce retornar a area com internet:
- **Dados serao enviados** automaticamente
- **Novas vistorias** serao baixadas
- **Status sera atualizado** em tempo real

### Indicadores de Status

- **Online**: Conectado ao servidor
- **Offline**: Trabalhando localmente
- **Sincronizando**: Enviando/recebendo dados
- **Pendente**: Dados aguardando sincronizacao

## Gerenciamento de Fotos

### Tirando Fotos de Qualidade

1. **Boa iluminacao**: Use luz natural quando possivel
2. **Foco no item**: Aproxime-se do equipamento
3. **Multiplos angulos**: Capture diferentes perspectivas
4. **Detalhes importantes**: Foque em problemas especificos

### Organizacao das Fotos

- Fotos sao **organizadas automaticamente** por item
- **Thumbnails** facilitam a visualizacao
- **Compressao automatica** economiza espaco
- **Backup local** garante que nada seja perdido

## Controle de Despesas

### Tipos de Despesas Comuns

- **Transporte**: Combustivel, pedagio, passagem
- **Materiais**: Pecas de reposicao, ferramentas
- **Alimentacao**: Refeicoes durante a vistoria
- **Hospedagem**: Quando necessario pernoite

### Comprovantes

- **Fotografe todos os recibos** e notas fiscais
- **Preencha dados completos** da despesa
- **Categorize corretamente** o tipo de gasto
- **Adicione observacoes** se necessario

## Dicas Importantes

### Boas Praticas

- **Sincronize regularmente** quando tiver internet
- **Carregue o dispositivo** antes de sair
- **Verifique o espaco** disponivel no aparelho
- **Faca backup** das fotos importantes
- **Revise os dados** antes de concluir

### Cuidados

- **Nao force fechamento** do app durante sincronizacao
- **Aguarde conclusao** antes de desligar o dispositivo
- **Mantenha o app atualizado** para melhor performance
- **Reporte problemas** para o suporte tecnico

## Resolucao de Problemas

### Problemas Comuns

#### "Erro de Sincronizacao"
1. Verifique sua conexao com a internet
2. Feche e reabra o aplicativo
3. Tente sincronizar novamente

#### "Foto nao carregou"
1. Verifique o espaco disponivel no dispositivo
2. Tire a foto novamente
3. Aguarde alguns segundos antes de continuar

#### "Vistoria nao aparece"
1. Puxe a tela para baixo para atualizar
2. Verifique se esta na aba correta
3. Aguarde a sincronizacao completa
